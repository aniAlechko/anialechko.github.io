# Alex Rivkin — Portfolio

Personal portfolio of Alex Rivkin, Product Designer.

[View the website](https://anialechko.github.io/)

## Source

- `dist/index.html`: page content and contact links.
- `dist/construction.css`: layout, type, and entrance animations.
- `dist/construction-entry.js`: entrance timing and character pose changes.
- `dist/construction-background.js`: animated background.
- `dist/images/` and `dist/fonts/`: current character images and fonts.

This repository contains the Alex Rivkin portfolio homepage and its publishing tools.

## Development

Requires Node.js 24 or later. No dependencies to install.

```sh
npm run dev
npm run check
npm run build
```

The static site is generated in `_site/`. Updates to `main` deploy automatically through GitHub Pages.
